# Название проекта
Сервис поиска наставников
## Назначение
Сервис для поиска наставников по различным специализациям
## Целевая аудитория
Школьники, студенты, люди, хотящие сменить квалификацию
## Предметная область
Образование
## Основные сущности
- Пользователь
- Наставник
- Специализация
- Заявка
## Основные функции
- Регистрация и авторизация пользователей и наставников
- Возможность пользователю оставить заявку на конкретную специализацию
- Возможность наставнику откликнуться на заявку

## Объектная модель

- `Entity` — базовый абстрактный класс сущностей проекта.
- `Person` — базовый класс участников сервиса.
- `User` и `Mentor` наследуются от `Person` и реализуют роли участников.
- `Specialization` описывает направление наставничества.
- `Application` хранит заявку и организует взаимодействие с наставником.

Объекты предоставляют строковое представление, преобразование в словарь и
восстановление из словаря. Пароль пользователя и список специализаций
наставника инкапсулированы. Полиморфизм демонстрируется общим методом `role`
классов `User` и `Mentor`.

## Хранение данных

Данные сохраняются в JSON-файлах каталога `data`. Модуль `app/storage.py`
загружает записи как объекты предметной области и сохраняет коллекции объектов
обратно в JSON.
## Веб-приложение Django

В рамках ПР5 к консольному проекту добавлен Django-проект
`mentor_service` и приложения:

- `homepage` — главная страница;
- `mentors_site` — список и карточки наставников;
- `specializations_site` — список и описания специализаций;
- `applications_site` — список и карточки заявок;
- `users_site` — список и карточки пользователей.

Веб-интерфейс читает данные из существующих JSON-файлов каталога `data`.
Консольная версия и объектная модель продолжают работать без изменений.

Основные адреса:

- `/` — главная страница;
- `/mentors/` и `/mentors/<id>/` — наставники;
- `/specializations/` и `/specializations/<id>/` — специализации;
- `/applications/` и `/applications/<id>/` — заявки;
- `/users/` и `/users/<id>/` — пользователи.

## Запуск тестов

Из корневой папки проекта выполните:

```bash
python -m unittest discover -s tests -v
```

## Запуск Django

Установите зависимости и запустите development-сервер:

```bash
python -m pip install -r requirements.txt
python manage.py runserver
```

После запуска главная страница доступна по адресу
`http://127.0.0.1:8000/`.
