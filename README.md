# Название проекта
Сервис поиска наставников
## Назначение
Сервис для поиска наставников по различным специализациям
## Целевая аудитория
Школьники, студенты, люди, хотящие сменить квалификацию
## Предметная область
Образование
## Основные сущности
- Пользователь
- Наставник
- Специализация
- Заявка
## Основные функции
- Регистрация и авторизация пользователей и наставников
- Возможность пользователю оставить заявку на конкретную специализацию
- Возможность наставнику откликнуться на заявку

## Объектная модель

- `Entity` — базовый абстрактный класс сущностей проекта.
- `Person` — базовый класс участников сервиса.
- `User` и `Mentor` наследуются от `Person` и реализуют роли участников.
- `Specialization` описывает направление наставничества.
- `Application` хранит заявку и организует взаимодействие с наставником.

Объекты предоставляют строковое представление, преобразование в словарь и
восстановление из словаря. Пароль пользователя и список специализаций
наставника инкапсулированы. Полиморфизм демонстрируется общим методом `role`
классов `User` и `Mentor`.

## Хранение данных

Данные сохраняются в JSON-файлах каталога `data`. Модуль `app/storage.py`
загружает записи как объекты предметной области и сохраняет коллекции объектов
обратно в JSON.
## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
